# GitLite · GitHub 安卓便捷版

一个用起来更省事的 GitHub 手机客户端：**PCL 启动器风格界面**，侧栏导航 + 卡片布局，
所有操作都调用 GitHub 官方 REST API —— 你在手机上做的，就是网页上做的那件事。

## 功能

- **登录**：粘贴 Personal Access Token（勾 repo 权限），token 只存在本机
- **一键发布**：Download/GitLite/项目名/ 放好文件，App 里点一下 → 自动匹配仓库/目录/提交说明，多文件合成 1 个 commit
- **选仓库引导**：独立的选仓库页（搜索 + 最近用过 + 我的仓库），配 30 秒引导页
- **仓库浏览**：列表带 Star 数；详情页有 Star / Fork / 关注 / Issues、说明、Topics、许可证、主页，可直接加星
- **文件操作**：目录浏览、查看、编辑并提交、新建文件、提交记录
- **界面**：竖屏滑出抽屉 / 横屏常驻侧栏；深色浅色跟随系统；全屏铺满，系统栏区域自绘，无黑边

## 技术

- 纯 Kotlin + android.*，不依赖 Gradle / AndroidX
- GitHub REST API v2022-11-28；批量发布走 Git Data API（blobs → tree → commit → ref），失败自动回退逐文件提交
